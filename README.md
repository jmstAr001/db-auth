# DCOMP207 Assignment 1 - PHP Authentication System and Dashboard

## Requirements
XAMPP (or WAMP/MAMP) with **PHP 8.1+** and MySQL/MariaDB.

## Setup (2 minutes)
1. Copy this folder to `C:\xampp\htdocs\dg-auth`.
2. Start **Apache** and **MySQL** in the XAMPP Control Panel.
3. Download the official Django Girls logo and save it as `assets/img/djangogirls-logo.png`
   (a placeholder shows until you do).
4. Open `config.php` and fill in STUDENT_FIRST_NAME, STUDENT_LAST_NAME, STUDENT_PROGRAM, STUDENT_ID.
5. Visit http://localhost/dg-auth/ - the database and table are created automatically.
   (Optional: import `database.sql` in phpMyAdmin instead.)

## Pages
index.php (home) | register.php | login.php | dashboard.php (login required) | logout.php
